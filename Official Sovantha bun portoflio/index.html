Systems & Workflow Automation

Onboarding Pipeline Automation

Designed and built a working Google Apps Script pipeline to tackle a manual, error-prone onboarding checklist for new joiners and members at Amador Club.

The script reads new rows from a single intake sheet, sends personalized welcome emails via Gmail, provisions a dedicated member folder in Google Drive from a template, and logs errors to a tracking tab. It uses guard clauses for missing data, installable triggers, and a custom “Amador Onboarding” menu so non-technical staff could run it.

Membership automation architecture

Webhooks from PeopleVine feed Applications, Trial Members, and Sponsor tables; interfaces surface pending approvals; scheduled jobs send day 3 / 7 / 14 / 21 follow-ups. Built with guard clauses so non-technical staff can run it.

A working solution built to prove the approach: turn a manual, error-prone checklist into a repeatable pipeline with personalized welcomes, templated folders, and no dropped touchpoints.
